# C Programming – Class Assignment Repository

This repository contains the **folder structure for assignments and practice programs** in the **C Programming** course.  
Students are expected to upload all the **programs, exercises, and examples taught in class** into the appropriate folders.

---

## Repository Structure

```
.
├── Arrays
├── Enumerations
├── FileHandling
├── Functions
├── Input_Output_ControlStatement_Chapter2
├── Pointers
├── Strings
├── Structure
└── Unions
```

Each folder represents a **topic covered in the C Programming course**. Students should upload their practice programs and assignments related to each topic inside the corresponding folder.

---

## Student Submission Guidelines

1. **Fork the repository** to your GitHub account.
2. **Clone the repository** to your local machine.

```
git clone https://github.com/yourusername/repository-name.git
cd repository-name
```

3. Navigate to the appropriate topic folder and **create a folder with your name**.

Example:

```
Arrays/YourName/
Pointers/YourName/
```

4. Add all the programs you practiced in class inside your folder.

5. Stage your changes:

```
git add .
```

6. Commit your work:

```
git commit -m "Added C programming exercises - Your Name"
```

7. Push your work to GitHub:

```
git push origin main
```

8. Create a **Pull Request** to submit your assignment (if required).

---

## Rules and Best Practices

- Do **not modify other students' folders**.
- Always create a **folder with your name** before uploading files.
- Use **clear file names** for your programs.
- Push your work **regularly after each class or practice session**.
- Make sure your programs **compile and run correctly** before submission.

---

All students must upload the programs taught in class in the correct topic folder as part of their **course practice and assignment work**.
